# 数字连连看 · 微信小游戏

两个人拿着同一张草稿纸：纸上随意写着成对的数字，挑两个相同的一笔连起来，再把纸交给对方。
笔尖碰到纸上的旧线，或绕回来碰到本笔先前画过的部分，画线的人立即输掉本局。

## 运行

**微信开发者工具**：导入本目录，把 `project.config.json` 里的 `appid` 换成自己的小游戏 AppID 即可运行。
`server/`、`tools/`、`test/`、`node_modules/` 已在 `packOptions.ignore` 中排除，不会进包。

**浏览器预览**（不需要微信开发者工具，含好友房）：

```bash
npm install
npm run dev        # http://localhost:8080
npm test           # 规则与联机服务的自动化测试
```

开两个浏览器窗口即可试好友房：一个点“邀请微信好友”，另一个打开页面上提示的邀请链接。

## 好友房需要一个联机服务

微信没有给小游戏提供现成的好友实时通道，所以好友房靠 `server/server.js`（一个很小的 WebSocket 转发服务）：

1. 部署 `server/server.js`（`PORT=8080 node server/server.js`），前面挂上 TLS，得到 `wss://你的域名`；
2. 把地址填进 `js/config.js` 的 `SERVER_URL`；
3. 在小游戏后台把该域名加入 **socket 合法域名**。

没配置时“邀请微信好友”会提示尚未配置，同屏对画不受影响。
服务只负责开房、配对、随机先手和转发笔迹；规则判定在两端各跑一份相同的引擎，
同一种子加同一串笔迹点必然得到同一结果。掉线即视为离开房间，暂不支持断线重连。

## 规则如何落到代码

| 策划案 | 实现 |
| --- | --- |
| 1–6 每个数字恰好两枚，随意散落 | `js/core/layout.js`：由种子生成，可在首页改成 1–4 … 1–9 |
| 点一下看看，按住拖动才算起笔 | `js/scenes/play.js`：按下只亮起另一枚；拖出 5 个单位才正式起笔 |
| 掠过别的数字继续画，到同号目标收笔 | `Game.extend`：数字字形不挡线；笔尖进入目标圈即收笔换人 |
| 碰旧线、本笔自交 / 自触 / 回描即负 | `Game._touch`：两条墨线中心距 ≤ 线宽即相触，首次接触处标叉 |
| 连成后数字外围的圈保留并挡线 | `Game.touchesRing`：墨线碰到已连数字的圈即负，连通性检查同样把圈算作障碍 |
| 贴得近也能过 | 判定用的线宽就是画出来的线宽，墨迹之间留有缝即合法 |
| 正常衔接、原地停顿允许 | 紧跟笔尖的 24 个单位不参与自触判定；停顿不产生笔迹点 |
| 中途抬手、表示画不完、超时 | `lift` / `giveUp` / `timeout` |
| 剩余数对确实都无路才直接判负 | `js/core/reach.js`：换手时做连通性检查，只在确定无路时判负 |
| 好友房同一张纸同一笔迹、可选每手 60 秒 | `server/server.js` + `js/net.js`；限时由正在画的一端裁定 |
| 原纸交换先手再来 | 同屏直接重开；好友房双方都选同一种方式才开 |

规则参数集中在 `js/core/consts.js`（纸面固定 720×1000 逻辑单位，各端等比缩放）。

## 目录

```
game.js / game.json / project.config.json   小游戏入口与配置
js/core/      规则内核：布局、判定、连通性（不依赖微信 API）
js/scenes/    首页、好友房等候页、对局
js/app.js     画布、触摸分发、联机消息分发
server/       好友房联机服务
tools/        浏览器预览（wx 兼容层 + 简易打包）
test/         node --test 用例
```
